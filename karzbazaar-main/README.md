# LoanIQ — Frontend Application

This directory contains the React 19 + TypeScript frontend for **LoanIQ**, the intelligent loan recommendation and repayment optimisation platform.

For full setup, backend execution, database initialisation, and test instructions, refer to the root [README.md](../README.md).

## Quick Start
```bash
# Install dependencies
npm install

# Run Vite development server
npm run dev

# Production build
npm run build
```
